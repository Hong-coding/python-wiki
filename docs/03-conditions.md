# 03. 조건문

조건에 따라 다른 코드를 실행할 때 `if`를 씁니다.

```python
if 조건:
    조건이 참일 때 실행
elif 다른_조건:
    앞 조건은 거짓이고 이 조건이 참일 때 실행
else:
    모든 조건이 거짓일 때 실행
```

!!! warning "들여쓰기가 문법입니다"
    파이썬은 중괄호 `{}` 대신 **들여쓰기(보통 공백 4칸)**로 코드 블록을 구분합니다. 콜론(`:`) 다음 줄은 반드시 들여 써야 하고, 같은 블록은 들여쓰기가 같아야 합니다. 어긋나면 `IndentationError`가 납니다.

## 비교 연산자와 논리 연산자

| 비교 | 뜻 | | 논리 | 뜻 |
|---|---|---|---|---|
| `==` | 같다 | | `and` | 둘 다 참 |
| `!=` | 다르다 | | `or` | 하나라도 참 |
| `<` `<=` `>` `>=` | 크기 비교 | | `not` | 참↔거짓 뒤집기 |
| `in` | 포함되어 있다 | | | |

`=`(대입)와 `==`(비교)를 헷갈리지 마세요. `0 < x < 10`처럼 비교를 이어 쓸 수도 있습니다.

## 참·거짓으로 취급되는 값

`0`, `0.0`, `""`(빈 문자열), `[]`(빈 리스트), `{}`, `None`은 **거짓**, 나머지는 **참**으로 취급됩니다. 그래서 `if name:`은 "이름이 비어 있지 않으면"이라는 뜻이 됩니다.

## 연습문제

1. 정수를 받아 짝수면 "짝수", 홀수면 "홀수"를 출력하세요.
2. 연도를 받아 윤년인지 판별하세요. (4로 나누어떨어지고 100으로는 나누어떨어지지 않거나, 400으로 나누어떨어지면 윤년)
3. `password` 문자열의 길이가 8 미만이면 "너무 짧음", 숫자가 하나도 없으면 "숫자 필요", 그 외에는 "통과"를 출력하세요. (힌트: `any(ch.isdigit() for ch in password)`)

??? success "해답"
    ```python
    # 1
    n = int(input("정수: "))
    print("짝수" if n % 2 == 0 else "홀수")

    # 2
    year = int(input("연도: "))
    if (year % 4 == 0 and year % 100 != 0) or year % 400 == 0:
        print("윤년")
    else:
        print("평년")

    # 3
    password = "abc12345"
    if len(password) < 8:
        print("너무 짧음")
    elif not any(ch.isdigit() for ch in password):
        print("숫자 필요")
    else:
        print("통과")
    ```
