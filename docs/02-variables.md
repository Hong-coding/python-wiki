# 02. 변수와 자료형

## 변수는 값에 붙인 이름표

```python
age = 35
```

`=`는 "같다"가 아니라 **"오른쪽 값을 왼쪽 이름에 붙인다(대입)"**는 뜻입니다. 이후 `age`라고 쓰면 35를 가리킵니다. 다시 대입하면 이름표가 새 값으로 옮겨 갑니다.

변수 이름 규칙:

- 영문자·숫자·밑줄(`_`)로 만들고, 숫자로 시작할 수 없습니다. (`user_name` ✅, `2nd` ❌)
- 대소문자를 구분합니다. (`Name`과 `name`은 다른 변수)
- 파이썬에서는 단어를 밑줄로 잇는 `snake_case`를 주로 씁니다.
- `if`, `for`, `class` 같은 예약어는 쓸 수 없습니다.

## 기본 자료형

| 자료형 | 이름 | 예 |
|---|---|---|
| `int` | 정수 | `0`, `-3`, `1_000_000` |
| `float` | 실수 | `3.14`, `1e-3` |
| `str` | 문자열 | `"안녕"`, `'abc'` |
| `bool` | 참/거짓 | `True`, `False` |
| `NoneType` | 값 없음 | `None` |

`type(값)`으로 자료형을 확인할 수 있습니다.

## 연산자

| 연산 | 뜻 | 예 → 결과 |
|---|---|---|
| `+ - *` | 더하기·빼기·곱하기 | `2 * 3` → `6` |
| `/` | 나누기 (항상 실수) | `7 / 2` → `3.5` |
| `//` | 몫 | `7 // 2` → `3` |
| `%` | 나머지 | `7 % 2` → `1` |
| `**` | 거듭제곱 | `2 ** 10` → `1024` |

`+=`처럼 줄여 쓸 수도 있습니다. `count += 1`은 `count = count + 1`과 같습니다.

## 형 변환

`input()`이나 파일에서 읽은 값은 **항상 문자열**입니다. 계산하려면 숫자로 바꿔야 합니다.

```python
"3" + "4"          # '34'  (문자열 이어 붙이기)
int("3") + int("4")  # 7
int("abc")         # ValueError — 숫자가 아닌 문자열은 바꿀 수 없음
```

## 실수 계산의 함정

```python
>>> 0.1 + 0.2
0.30000000000000004
```

컴퓨터는 실수를 2진수로 저장하므로 아주 작은 오차가 생깁니다. 화면에 보여 줄 때는 `round(x, 2)`나 `f"{x:.2f}"`를 쓰고, 돈 계산처럼 정확해야 하면 `decimal` 모듈을 씁니다.
